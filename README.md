# 双缝干涉条纹测量与实验分析

这是一个基于 Streamlit 的双缝干涉实验辅助工具。程序从实验图片中检测亮条纹，经过尺度标定后计算实际条纹间距，并可使用双缝干涉公式计算理论间距或反算实验参数。

## 主要功能

- 上传 JPG、PNG 或 BMP 干涉图片；
- 在图片上点击两点完成像素—毫米标定；
- 使用 CLAHE、背景去除、一维平滑和标准化改善亮度信号；
- 自动检测亮条纹并计算平均间距与标准差；
- 展示原始投影、估计背景、处理后信号和峰值位置；
- 计算理论条纹间距，或反算波长、双缝间距和屏距；
- 导出 CSV、JSON、标记图 PNG 和 PDF 实验报告。

## 安装与运行

建议使用 Python 3.11：

```bash
python -m pip install -r requirements.txt
streamlit run streamlit_app.py
```

Windows 用户也可以双击 `start_app.bat` 启动。使用网站期间请保持弹出的终端窗口打开；关闭窗口会同时停止本地网站。

## 使用流程

1. 上传包含双缝干涉条纹的图片。
2. 在图片上选择两个标定点，输入两点之间的实际距离。
3. 执行条纹分析。一般情况下可以保留默认预处理参数。
4. 根据实验目的计算理论间距或反算物理参数。
5. 下载数据、标记图片或 PDF 报告。

## 参数说明

- **峰值灵敏度**：越低越容易检测弱条纹，也更容易引入噪声峰。
- **最小峰间距**：限制两个亮条纹峰可以同时存在的最小像素距离。
- **背景估计尺度**：用于估计缓慢变化的光照或衍射包络，应明显大于单条条纹宽度。
- **一维平滑强度**：用于抑制投影信号中的细小噪声，过大会使相邻条纹粘连。

## 测量限制

当前算法按竖直方向平均图像，因此更适合近似竖直、横向排列的规则条纹。明显倾斜、弯曲、严重过曝或存在强透视变形的图片可能产生较大误差。输出精度也取决于标定准确性。
